# BELLA-μ — Muon Tracking and Momentum Reconstruction

**Lawrence Berkeley National Laboratory · DOE SULI internship · Spring 2025**

The BELLA-μ experiment investigates muon production using a laser plasma accelerator. Muons can pass through thick materials, making them useful for imaging structures that ordinary imaging methods cannot penetrate.

## My Contribution

- Developed C++ and Python tools to process data from a six-plane ATLAS detector telescope and reconstruct muon tracks.
- Contributed the EventLoaderYarr module to the Corryvreckan reconstruction framework, converting raw detector data into compatible events.
- Analyzed detector alignment and track deflection through a magnetic field to estimate momentum, enabling BELLA's first preliminary momentum measurements of accelerator-produced muons.
