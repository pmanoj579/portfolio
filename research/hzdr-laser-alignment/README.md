# HZDR — Laser Alignment and Optical Controls

**Helmholtz-Zentrum Dresden-Rossendorf · Dresden, Germany · Summer 2023**

This project developed an optical setup for laser-based ion filtering in the HAMSTER accelerator mass spectrometry facility.

## My Contribution

- Built a Qt interface integrated with EPICS to control motorized mirrors and lens stages, configure motion parameters, and display position and movement status.
- Modeled beam divergence to select lenses and their spacing.
- Assembled and aligned an optical test setup, validating laser focusing across the full planned beam path.
